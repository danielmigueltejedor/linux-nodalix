# Linux Nodalix

Kernel de Nodalix OS basado en CachyOS. Este repositorio mantiene fuentes y configuración fijadas por commit, parches específicos de Nodalix, empaquetado Arch y pruebas. **No sigue automáticamente las actualizaciones de CachyOS.**

> Inicialización: la configuración completa, scripts y CI se desarrollan en una rama de trabajo antes de publicar una versión estable.
